# 易测 · 预设兑换码清单

写入方式：后端启动时自动补缺，或执行 `cd backend && npm run seed:codes`，或在管理后台「兑换码」页点击「补充预设兑换码」。

| 兑换码 | 类型 | 权益 | 可用次数 | 说明 |
|--------|------|------|----------|------|
| `YICE-LIFE-2026` | 永久会员 | 无限解读 | 200 | 2026 内测通用批次 |
| `YICE-LIFE-LAUNCH` | 永久会员 | 无限解读 | 500 | 公测首发活动 |
| `YICE-FOUNDER` | 永久会员 | 无限解读 | 20 | 创始用户限量 |
| `YICE-PARTNER` | 永久会员 | 无限解读 | 50 | 合作方 / KOL |
| `YICE-VIP-SOLO` | 永久会员 | 无限解读 | 1 | 单人尊享 |
| `YICE-STAFF` | 永久会员 | 无限解读 | 30 | 团队内部测试 |
| `YICE-EVENT-2026` | 永久会员 | 无限解读 | 100 | 线下活动（2026-12-31 前有效） |
| `YICE-MEMBER-BETA` | 会员批次 | 无限解读 | 300 | 公测渠道统计 |
| `YICE-MEMBER-GIFT` | 会员批次 | 无限解读 | 100 | 礼品卡配套 |
| `YICE-CREDIT-01` | 解读额度 | +1 次 | 2000 | 补 1 次免费解读 |
| `YICE-CREDIT-03` | 解读额度 | +3 次 | 1000 | 补 3 次 |
| `YICE-GIFT-05` | 解读额度 | +5 次 | 500 | 活动礼包 |
| `YICE-CREDIT-10` | 解读额度 | +10 次 | 200 | 重度用户礼包 |
| `YICE-REFERRAL-BONUS` | 解读额度 | +1 次 | 5000 | 邀请补发 |
| `YICE-CS-FIX` | 解读额度 | +3 次 | 500 | 客服补偿 |
| `YICE-TRIAL-EXTRA` | 解读额度 | +2 次 | 3000 | 试用延长 |
| `YICE-PAY-FAIL` | 解读额度 | +1 次 | 200 | 支付异常补单 |

**类型说明**

- **永久会员 / 会员批次**：兑换后开通无限解读（`lifetime` / `member` 权益相同）。
- **解读额度**：在游客免费 5 次基础上增加 `bonus_credits`，适合补偿与活动。

**安全提示**：生产环境请定期轮换高价值码，勿将 `YICE-VIP-SOLO` 等单人码公开张贴。
