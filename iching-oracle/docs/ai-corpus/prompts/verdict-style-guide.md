# P6 · 断语风格指南

## 格式

- 长度：20–40 字
- 结构：**一句判断**；可含「但」转折
- 禁止：纯「宜观察」「待定」「随缘」

## 三类模板

### 肯定（可行动）

- 例：可小步试，先验证再放大，忌赌气一搏。
- 例：窗口已开，宜谈条件，勿裸辞。

### 否定（宜守）

- 例：不宜现在硬推，先补退路再动。
- 例：当下以稳为主，大动易失筹码。

### 观望（有前提）

- 例：可准备不可下注，六周后再议进退。
- 例：势未明，先收集信息，勿做不可逆动作。
