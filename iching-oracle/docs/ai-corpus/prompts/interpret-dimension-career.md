# P4 · 事业类分维 Rubric

## 维度标题

1. 时机判断  
2. 隐患与阻力  
3. 具体建议  
4. 结果走向  

## 每维必须回答

| 维度 | 锚点 |
|------|------|
| 时机判断 | 现在动/不动/先观察？依据动爻与变卦说清窗口 |
| 隐患与阻力 | 卡住的是人、钱、信息还是情绪？1–2 个具体阻力 |
| 具体建议 | 本周–6 周内 2–3 步，含对话对象或验证动作 |
| 结果走向 | 惯性走 1–2 季度落点；主动调整可改写什么 |

## 语气

像懂职场的顾问：谈筹码、退路、下家、交接。
