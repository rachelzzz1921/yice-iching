# 易测 · AI 解读语料与 Prompt 生产任务书

> 交给内容 / Prompt 工程师。工程侧负责接入；**本任务不写代码**。

## 一、产品背景

易经 **事占** App：问事类型 → 结构化问题 → 四种起卦 → 本卦/变卦/动爻 → **5 段式解读** + 深入追问。

**内测共识**：语气更确定、贴题；卦辞现代白话；禁止每卦重复套话；观象辅助决策非宿命算命。

**架构**：层1 facts → 层2 语料 → 层3–5 解读（计划加大 AI）；追问已 100% 智谱。

## 二、四类变更（必按新类设计）

| 新标签 | ID | 说明 |
|--------|-----|------|
| 事业 | `career` | 保留 |
| 家庭 | `family` | **新**，从原 decision 独立 |
| 情感 | `relationship` | 原感情改名，不扩友情，可含社交 |
| 健康 | `health` | 保留 |

需交付：family 四维定义、20 条预设问句、原 decision 问句迁移表。

## 三、要解决的问题

- 变卦套话重复 → 按键多版本 + blacklist
- 语气模棱两可 → 直断 + 忌 + 7 日一步
- 缺现代语 → guaci-plain 每卦/爻 ≤40 字
- 范例不足 → curated ≥80 条

## 四、解读输出结构（固定 6 块）

```
【卦象气场】
【维度1–4】← 因 category 而异
【断语】20–40 字
```

附加五字段：一句话定性 / 时间节点 / 行动锚点。

## 九、验收标准

1. 每维首句贴用户问句核心词  
2. 断语为一句判断，非纯「宜观察」  
3. 不出现 blacklist 句  
4. 引爻辞后跟 ≤40 字白话  
5. 建议含 7 日内 1 动作 + 6–8 周验证窗  
6. health 含「辅理不代医」一次  

## 十、工程约束

- 类别 ID：`career | family | relationship | health`
- 范例 key：`本卦|变卦|category|动爻`，无变卦：`屯||family|1`
- 禁止：「我是 AI」、Markdown `#` 标题、emoji
- 全量 AI 输出预算 ~1600 tokens；超时 55s 回退本地
